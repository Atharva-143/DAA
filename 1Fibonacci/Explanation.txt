# DAA EXPERIMENT 1: FIBONACCI NUMBERS

## 1. AIM

To write recursive and non-recursive C++ programs to generate Fibonacci numbers and analyze their time and space complexity.

## 2. THEORY

The Fibonacci series is a sequence in which each number is the sum of the previous two numbers.

Example: 0, 1, 1, 2, 3, 5, 8, 13, 21...

**Formula:**
F(n) = F(n-1) + F(n-2)

The first two Fibonacci numbers are 0 and 1.

There are two ways to generate the series:

* **Non-recursive:** Uses loops to calculate Fibonacci numbers.
* **Recursive:** Uses a function that calls itself to calculate Fibonacci numbers.

## 3. CODE EXPLANATION

### A. Header Files and Namespace

`#include <iostream>`

* Includes the input/output library.
* Allows us to use `cin` and `cout`.

`using namespace std;`

* Allows us to use standard library names without writing `std::` before them.

### B. Recursive Function

```cpp
int fibonacci(int n)
{
    if (n <= 1)
        return n;

    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

**Explanation:**

* `int fibonacci(int n)`: Defines a function that accepts an integer and returns the corresponding Fibonacci number.
* `if (n <= 1)`: Checks the base condition.
* `return n`: Returns 0 when n is 0 and 1 when n is 1.
* `fibonacci(n - 1) + fibonacci(n - 2)`: Calculates the current number by adding the previous two Fibonacci numbers.

**Example:**

For `fibonacci(4)`:

F(4) = F(3) + F(2) = 2 + 1 = 3

The function keeps calling itself until it reaches the base condition.

**Why is the base condition necessary?**

It stops further recursive calls. Without it, the function would continue calling itself until the program ran out of stack space.

### C. Main Function and Variables

```cpp
int main()
{
    int n, choice;
    int a, b, c;
```

* `main()`: The execution of the program begins here.
* `n`: Stores the number of Fibonacci terms required.
* `choice`: Stores the user's menu selection.
* `a`, `b`, `c`: Store the current, next, and calculated Fibonacci numbers in the non-recursive method.

### D. Menu and User Input


* Displays two options to the user.

The program then accepts the number of terms using `cin >> n`.

### E. Input Validation

```cpp

{
    cout << "Enter a positive number of terms.";
    return 0;

```

* Checks whether the number of terms is positive.
* If `n` is zero or negative, the program displays an error message.
* `return 0` terminates the program.

This prevents the program from generating an invalid number of terms.

### F. Switch Statement

```cpp

```

The switch statement selects the method according to the user's choice.

* `case 1`: Executes the non-recursive method.
* `case 2`: Executes the recursive method.
* `default`: Displays an error message if the user enters an invalid choice.
* `break`: Exits the selected case and prevents execution from continuing into the next case.

### G. Non-Recursive Method

```cpp
a = 0;
b = 1;

for (int i = 0; i < n; i++)
{
    cout << a << " ";
    c = a + b;
    a = b;
    b = c;
}
```

**Explanation:**

1. `a = 0` and `b = 1` initialize the first two Fibonacci numbers.
2. The loop runs `n` times to print the required number of terms.
3. `cout << a` prints the current Fibonacci number.
4. `c = a + b` calculates the next number.
5. `a = b` moves the second number into the first position.
6. `b = c` stores the newly calculated number.
7. The loop repeats until all terms are printed.

**Example for the first iteration:**

Initially, a = 0 and b = 1.

* Print 0.
* Calculate c = 0 + 1 = 1.
* Update a = 1 and b = 1.

The next iteration prints 1. The process continues to generate the series.

### H. Recursive Method

```cpp
cout << "Fibonacci Series: ";

for (int i = 0; i < n; i++)
{
    cout << fibonacci(i) << " ";
}
```

**Explanation:**

* The loop runs from `i = 0` to `i < n`.
* `fibonacci(i)` calculates the Fibonacci number for the current value of `i`.
* The result is printed.
* The loop continues until the first `n` Fibonacci numbers have been displayed.

For example, when `i = 4`, `fibonacci(4)` returns 3.

**Important:** The recursive function calculates each term independently. This causes repeated calculations, making it slower than the non-recursive method.

### I. Return Statement

```cpp
return 0;
```

Indicates that the program has finished successfully.

## 5. TIME AND SPACE COMPLEXITY

### Non-Recursive Method

* **Time Complexity: O(n)** — The loop executes n times, performing a constant amount of work per iteration.
* **Auxiliary Space Complexity: O(1)** — Only a fixed number of variables are used, regardless of n.

### Recursive Method

* **Time Complexity: O(2^n)** — The basic recursive function repeatedly calculates the same Fibonacci values. This is an exponential upper bound.
* **Auxiliary Space Complexity: O(n)** — Recursive calls can reach a maximum depth proportional to n.

### Which Method Is Better?

The non-recursive method is more efficient because it takes O(n) time and O(1) auxiliary space. The basic recursive method takes exponential time because of repeated calculations.

## 6. IMPORTANT ORAL QUESTIONS AND ANSWERS

**Q1. What is the Fibonacci series?**

A sequence in which each number is the sum of the previous two numbers. It begins with 0 and 1.

**Q2. What is the recurrence relation for Fibonacci numbers?**

F(n) = F(n-1) + F(n-2), for n >= 2.

**Q3. What is recursion?**

Recursion is a programming technique in which a function calls itself to solve a problem.

**Q4. What is iteration?**

Iteration is the repeated execution of statements using loops such as `for` and `while`.

**Q5. What is a base condition?**

A condition that stops recursive calls. In our program, `n <= 1` is the base condition.

**Q6. Why do we use recursion in this program?**

To calculate Fibonacci numbers by calling the same function with smaller input values.

**Q7. Why is the non-recursive method faster?**

It calculates each next number directly without repeatedly calculating previous Fibonacci values.

**Q8. What is the time complexity of the non-recursive method?**

O(n), because the loop runs n times.

**Q9. What is the time complexity of the recursive method?**

O(2^n) as an upper bound for the basic recursive approach.

**Q10. What is space complexity?**

Space complexity measures the memory required by an algorithm during execution.

**Q11. What is the auxiliary space complexity of the recursive method?**

O(n), because recursive function calls use the call stack.

**Q12. What is the auxiliary space complexity of the non-recursive method?**

O(1), because it uses a fixed number of additional variables.

**Q13. What is the purpose of the switch statement?**

It selects which Fibonacci method to execute based on the user's choice.

**Q14. What is the purpose of the break statement?**

It terminates the current switch case and prevents execution from falling through to the next case.

**Q15. What happens if the user enters an invalid choice?**

The `default` case displays "Invalid choice!".

**Q16. Can Fibonacci numbers be calculated without recursion?**

Yes. They can be calculated using loops and two variables to track consecutive numbers.

**Q17. What is the purpose of `#include <iostream>`?**

It provides input/output functionality through `cin` and `cout`.

**Q18. What is the difference between recursion and iteration?**

Recursion uses repeated function calls, while iteration uses loops.

**Q19. What happens if n = 1?**

The program prints only the first Fibonacci number, which is 0.

**Q20. What is the output for n = 5?**

0 1 1 2 3
